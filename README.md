# Sales Tax Calculator API for Zapier

A Zapier integration for requesting a sales tax result from a Zap.

**Status: scaffold only. This integration is not published or ready to install.**

## Planned scope

- Connect with a Sales Tax Calculator API key.
- Add a “Calculate tax” action with mapped transaction fields.
- Return the API outcome, tax, total, and request ID to later Zap steps.
